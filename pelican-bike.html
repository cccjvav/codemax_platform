动画拆解

场景里每一处动态都可以在下面的卡片里找到出处 —— 技术全部是 SMIL 三件套。

1车轮与传动

双轮辐条、牙盘齿盘各自 rotate 自转，轮 0.7s 一圈、牙盘 1.4s 一圈（传动比 2:1）； 链条与波浪、路面虚线一样，用 stroke-dashoffset 流动来冒充平移。

看哪里：辐条反光片、牙盘齿、链条。

2双腿踩踏

大腿—小腿是一条二次贝塞尔曲线，用 d 属性 8 关键帧形变； 双脚用 animateMotion 锁定在牙盘圆周上；远侧腿 begin="-0.7s" 实现半周期相位差。

看哪里：膝盖起伏与脚踏，脚永远踩在踏板上。

3身体起伏

整车（含骑手）0.7s 上下浮动 5px，地面阴影同步缩放；喉囊、围巾尾带、尾羽用同频的 d 形变 / 旋转抖动；脚踏自带反向旋转保持水平。

看哪里：车身与阴影、喉囊、篮中鱼尾。

4三层视差

路面、中景、前景是三个速度的无缝循环：路面 633px/s，中景棕榈路灯 316px/s， 前景栅栏 800px/s —— 越近越快。瓦片内容按周期整数倍铺设，接缝处严丝合缝。

看哪里：棕榈、路灯、路牌、栅栏向后掠去。

5海洋与天空

三排波浪虚线以不同速度流动；帆船浮沉加摇摆两层嵌套；飞鱼沿抛物线 animateMotion 跃水，出水瞬间才显形；灯塔光束 9s 旋转一周。

看哪里：海平面、帆船、灯塔，每 9 秒一条飞鱼。

6脸部微表情

眼睛 4.4s 眨一次：眼白与瞳孔的 ry 同步压扁，高光同步熄灭； 太阳光芒 36s 缓转，海鸥振翅、星星闪烁各有各的时钟。

看哪里：盯住鹈鹕的眼睛等 4 秒。

技术实现说明
  • 零脚本：全文无 script 标签、无事件属性、无外链资源（除 SVG 命名空间声明外无 http 引用）， 断网双击即可看。主题切换靠原生单选框的 :checked + CSS 变量，纯样式换肤。
  • 同步原理：骑行相关动画共用 1.4s / 0.7s 两档时间基准；远侧腿脚踏用 begin="-0.7s" 负相位实现半周期差；所有循环都是一开页就对齐的 SMIL 时钟，不会漂移。
  • 速度匹配：轮周 2π×70≈440px / 0.7s ≈ 628px/s，路面虚线 190px / 0.3s ≈ 633px/s， 两者基本一致，所以车轮看起来真正「压着路面」滚动。
  • 无缝循环：中景瓦片 600px、前景瓦片 400px，内容按瓦片整数倍铺设， 平移动画位移恰好等于一个瓦片宽度，首尾帧完全重合。
  • 可复用定义：车轮、棕榈、路灯、云等都收在 defs 里用 use 引用， 动画写在定义内部（如树冠摇摆），所有实例自动同步。
  • 无障碍：svg 带 role="img" 与中文 aria-label； 主题单选框原生支持 Tab / 方向键操作；如实说明一点：浏览器不会因 prefers-reduced-motion 自动暂停 SMIL，本页首帧即完整构图，静态下同样可读。
  • 兼容：Chrome / Edge / Firefox / Safari 均完整支持本页用到的 SMIL 子集 （位移、旋转、路径形变、路径运动、虚线偏移）。
