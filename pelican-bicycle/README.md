# 🚲 鹈鹕骑自行车 · Pelican Riding a Bicycle

一个**单文件**、**零依赖**的 2D 动态页面：一只戴着头盔、嘴里还叼着条鱼的呆萌鹈鹕
骑着自行车悠哉前行。全部画面由 SVG 矢量绘制，全部动画由原生 SMIL 驱动
（仅用少量原生 JS 实现空格/按钮暂停），无任何外部图片或第三方 JS 库。

## 打开方式

直接用浏览器打开 `index.html` 即可（也可是任意静态服务器）。

- **空格键** / 右上按钮 / 点击画面：暂停 / 播放
- **↻ 重置**：回到第 0 帧
- `prefers-reduced-motion` 用户自动以暂停态打开

## 动画机制

| 要求 | 实现 |
| --- | --- |
| 车轮匀速滚动 | 车轮半径 560/2π（周长 560px），每 1.2s 匀速转 2 圈 = 地面速度 933.3 px/s，与路面滚动严格一致（无打滑） |
| 踏板同步旋转 | 曲柄每 1.2s 转 1 圈（2:1 单速齿比）；两侧踏板各带一个 0→−360° 的反向 `animateTransform`，平台全程保持水平 |
| 两段式腿部 IK | 大腿/小腿各 110px，髋关节位置含"每圈两次"的起伏曲线；对曲柄整圈 96 个采样点做解析式两段 IK（余弦定理解膝角），以 `values` 列表写入 SMIL。脚掌贴合脚踏的最大偏差 **< 0.04 px** |
| 髋部起伏同步 | 身体、双腿、翅膀共用同一条 97 点采样起伏曲线，髋部起伏被完整 bake 进 IK，脚永不离开脚踏 |
| 背景无缝滚动 | 5 层视差（远云 70 px/s → 前景 1167 px/s），每层位移量都是其 tile 宽度的整数倍，循环无缝 |
| 首尾帧闭环 | 每条动画首末值相同（或等效：旋转差为 360° 整数倍、链条 dash 位移为周期整数倍）；自动校验渲染 t=0 与 t=T 逐字节一致 |

小彩蛋：喉囊随踩踏频率鼓动、嘴里的鱼尾不停扑腾、尾羽/小旗随风摆动、
眼睛会眨会瞟、链条虚线按真实方向流动。

## 文件

- `index.html` —— 交付物（单文件，约 40KB）
- `generate.py` —— 生成器：解析式 IK + SMIL 采样代码，含 42 项自动校验
  （IK 精度、循环闭合、tile 无缝、渲染回环、逐像素探针）

```bash
python3 generate.py          # 重新生成 index.html 并运行全部校验
python3 generate.py --check  # 仅校验
```

校验内容包括：脚掌-脚踏追踪误差（数值 + 渲染探针）、车轮/路面速度一致性、
链条速度一致性、38 条动画的首尾闭合、滚动层 tile 整除、
机械子集 t=0 与 t=T 渲染逐字节一致、以及 30+ 个关键位置的颜色探针
（头盔、喉囊、鱼尾、车座、双腿、挡泥板、树、山、云……）。
