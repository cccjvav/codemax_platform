# 第十五批：核验进程监督、本地告警与恢复演练

## 本轮范围

在第十四批0cc20a3基础上继续，不改退款政策/默认开关，不增依赖/schema/API。完整账本仍0017，历史SQL保持不变。

- worker可选私有状态文件，启动/循环有时限；SIGTERM协作退出，失败非零且脱敏，未知租约不清零、不立即重排。
- OS单写锁、同目录原子JSON、状态/告警变化日志；独立stdlib检查命令不读.env、连接数据库或商户。
- 区分freshness与业务告警，attention/过期租约/retry/到期积压/逾期等待有固定代码；不发送短信、邮件、Webhook，不承诺自动送达。
- Compose默认不启动的profile、有限失败重启、独立状态卷、覆盖Web健康探针；模板固定SEND/AUTO关闭，VERIFY仍需明确授权。
- 专用环境真实子进程退出、硬杀、重新启动；持久租约不能提前偷领，过期新token拒旧结果；没有真实退款或业务库操作。

健康状态最多滞后120秒；--once退出不算常驻健康；告警不当重启指令，Docker unhealthy不自动重启。状态文件不是财务凭证、备份或WORM。监控不改变原准备、授权、停止、8次预算或下载权益。
