## 没有照搬的建议与评级

1. A 建议非法 UTF-8 回调直接 200。本批不采纳：它尚未验签，不能确认已成功处理；返回有界 400，过大返回 413。只有已认证且按当前业务处理/忽略的事件才能 SUCCESS。完整商户回调政策仍需真实联调。
2. 收款码并非刚发现的未知秘密：`app/config.py` 和 TD-225 有此前用户上传/确认记录。本批不删除、不轮换、不改变默认收款人；它是支付用途和上线政策问题，不是已经确认的 API 密钥泄露。
3. 不给 Draw.io 的任意 autosave/save 事件自动设置 ready。现有 origin/source/epoch/load/export 相关性有真实作用；不能为了“兜底”取消时序保护。仍需浏览器协议/脏稿验收。
4. CPU 池创建竞态未在当前调用链成立：`_get_executor` 由同一事件循环同步调用，创建段没有 await，没有线程调用方。删除重复 import，但不为尚未证实的线程竞态添加锁。
5. 根 README 的统计漂移确实存在，但不等同于可直接接管账号的 P1 安全漏洞。历史验收节有日期时，旧数字是有效历史证据，不全部改成今天的数字。
6. GitHub 显式标记触发是此前在 workflow_dispatch 权限不足时经用户授权的后备。不直接删除可用测试入口；普通提交不含 marker，不调用 Agnes。它依赖分支写权限信任，仍不是环境审批或花费预算。
7. “没有发现明确 SQL 注入/SSRF/XSS”等报告结论只能限定于其范围，不代表以后无需复查；也不能把未证实的攻击宣称为已利用漏洞。
