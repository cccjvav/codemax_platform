# 第十七批：只读渠道日账与差异报告

## 范围与交付

基于已发布56f4aa7。默认关闭`WX_BILL_READ_ENABLED`，新增显式运维CLI、有界可信ALL日账下载、严格解析、当前商户/app Native CNY付款双向差异和私有JSON报告。没有新增依赖/schema/公开API/网页批量操作，完整迁移仍0017；没有真实账单、业务库或真实资金操作。

- 已验签申请元数据→固定HTTPS主站两个官方路径→无签名下载文件按SHA1核对→严格27列/7项汇总。拒绝重定向、压缩、旧格式、未知身份/日期、重复、截断及超预算；无账单/错误不是零交易。
- 4MiB/5000行、金额整数分，比较订单金额而不是券后的应结金额；ALL退款行仅发起观察，任何冻结状态不构成退款完成依据。
- 显式确认实际数据库目标和商户，迁移预检结束后出网；PG只读重复读快照按UTC+8付款日双向检查，兼查原号跨日/跨单冲突。迟到凭证需要新报告，不修改既有报告。
- 私有runtime文件独占原子发布、失败清临时文件，HTTPX下载token脱敏，CLI不输出原始第三方异常/SQL。报告不含openid、商品、交付key或原账单；有敏感订单参考，摘要不等于签名包/WORM，保留期限/ACL须另设。
- 不改变订单/凭证/事件/复核/队列或下载权益；不调用settle、退款或关单，不自动创建差异处理任务或结案。

操作、退出码、差异码处理和官方依据集中于[日账指南](../docs/WECHAT_BILLS_GUIDE.md)。Windows新手入口已经补Conda/CMD顺序步骤，保留关闭门禁和专用测试库边界。

## 官方核对与设计取舍

读取申请交易账单4013071227、下载账单4012791889、格式4013071246（2026-01-16版）。申请示例`/v3/bill/downloadurl`与下载示例`/v3/billdownload/file`不同，仅白名单支持这两条，不泛化外部地址。文件应答没有微信签名，不削弱普通JSON应答验签；SHA1来自已认证元数据，另留SHA256内容定位。

付款行退款ID是0，不是空字符串；退款行交易时间是发起时间，生成后状态不更新。当前UTC+8口径、原合同/应结/申请退款金额差异明确写入代码和手册。资金账/fundflow接口不是本批交易日账，不混作银行余额或正式结算。

取舍见TD-256：先运维只读对照，不为报告引入新权限表或把订单事件滥用为整张账单存储；不接上传、不支持旧版/压缩/服务商/大批量，不自动整改。退款双向完成对账、部分退款、会计结算及网页审批需另设计。
